# Neutral installed public version proof

Run actual AgentFootprint public CJS and ESM APIs from a new private consumer root containing the
admitted archives. Source-checkout self-reference is refused. Resolver-only processes bind all
three entries to their exact role/format export-map targets and installed member hashes before imports; real scripted MockProvider runs then read
the normal recording-envelope producer versions. Expected versions come from the admitted inputs.

The export adapter accepts only the admitted AF map's explicit import/require branches, either
direct strings or its native types/default objects. Unknown condition shapes refuse; this does
not interpret a second general Node resolver. Swapped admitted members, wrong-format targets,
query/fragment resolver output and source-checkout entries fail before public imports. Filesystem
aliases such as macOS /var resolve to the same canonical installed target before comparison.

The direct Node port uses argument arrays, a fixed 30-second/1-MiB bound and a minimal environment
without credentials, NODE_PATH or NODE_OPTIONS. Process outcomes/stdout/stderr and specimen hashes
survive outside the removed install root. Every process is guarded by installed bytes/one-copyFT,
setup and specimen checks. All owned dependencies/processes are bounded and cleaned in finally.

The code does not publish, invent an export, change peers or replace native CTS/MTS/full gates.
Tiny fake packages test orchestration only; actual AF source/build/archive/runtime proof requires a
hosted complete source cohort. Proposed API specimen source: Root's AF383 public-version proposal,
reviewed alongside immutable native sources; null recordings and hardcoded major assertions were
corrected on adoption. A successful version string alone is not archive/source provenance.
