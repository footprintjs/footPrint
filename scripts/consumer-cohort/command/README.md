# Paired command boundaries

Before-guard refusal launches no command. After every attempted child, including a thrown or
nonzero command, run the after guard. Preserve the actual thrown value; if both outcomes fail,
keep the operational failure first and the guard failure second. Invalid/skipped outcomes cannot
be success. Valid nonzero outcomes remain available to the owning producer/consumer verdict law.
No command or policy comes from the plan. This helper does not install, retry or waive a gate.
