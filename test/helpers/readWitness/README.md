# Native oracle domain

One folder, one job: passively observe native same-frame tombstone/read calls and report when the 9.28 baseline exhibits #124. No fixture runtime, generated program, opcode list, product-record model, heap, retained slot, identity graph, encoder or cross-engine comparator is imported here.

`captureNative(engine, leg, fn)` and `captureNativeSync(engine, leg, fn)` return `{ value, native }`. The structural engine port needs only StageContext and TransactionBuffer prototypes. Original methods run once with their exact receiver, arguments and return/throw. Capture stores only undefined/defined bits, native owner/address/order/buffer/epoch facts and referenced native get IDs; it never inspects returned values. Native method descriptors restore in finally. An unsupported descriptor, capture bound or conflicting buffer owner fails classification; it never becomes an in-domain answer.

`sameStageDeletedReadInputs(receipt)` selects actual returned reads backed by one physical canonical get, after a successful same-frame/same-buffer/epoch ancestor-or-exact tombstone and before re-establishment. Explicit delete and set(undefined) are tombstones. Any intervening overlapping native mutation keeps comparison strict, including an ambiguous throwing mutation; commit attempts advance the epoch. Foreign frames, namespaces and pre-tombstone reads do not create a selection. No baseSnapshot or private lookup/fallback reconstruction is necessary: the observed final native read's undefinedness is the fact. The selector is shared by BOTH functions below.

`oracleDomain(baselineReceipt)` returns typed in-domain or out-of-domain with actual violating read/get/tombstone references. Only selected native returns whose bit is defined exclude the program. Empty or missing caller classification flags are irrelevant. `assertBuildDeletedReadsUndefined(buildReceipt)` ALWAYS checks the same native law and fails a lying build; baseline classification is not an argument.

The callers own unchanged in-domain full comparisons and old9.30/R13 handling. They also own unconditional build invariants, per-leg checkpoint-start, fixed-seed exclusion counts and the explicit corpus domain list, including independent old ADMITTED evidence. `sampleCounts` is Root-owned. Out-of-domain programs lose differential coverage for bugs that evade the build-only laws and direct witnesses; that residue must be stated. No helper here can waive those caller checks.

Files: observationTypes is import-free facts; data holds descriptor/path/definedness helpers; observation owns native wrappers; selector binds local native inputs; domain classifies and asserts the build law; capture owns synchronous/asynchronous lifetime. Adjacent inert tests are delegation/rule controls, not native proof. native.test compares actual observed vs ordinary execution on BOTH engine imports using the original independent witness. All new tests and copied-source mutations must be executed by Root before claims.
