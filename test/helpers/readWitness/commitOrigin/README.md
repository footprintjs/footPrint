# Native commit origin

Snapshots an existing native encoder return below an outer commit rewrite. The explicit baseline profile reads the complete encoder payload; the record profile joins the rows with the actual surviving-redacted-path output. Both use the caller's existing witness serialization, omitting only its established trace.readKeys field. No encoder, admission or replay runs twice.

The same native buffer observer begins and finishes the capture on the actual receiver, mode and epoch. Missing, repeated, unsupported or wrong-mode outputs yield no proof. A later rewritten outer payload must differ from this inner observation, so a valid deleted read cannot excuse an unrelated trace row. Actual native profile checks remain distinct from the adjacent inert controls.

Methods forward their original this, arguments, return and throw. Restoration attempts every original descriptor. Observed encoder bytes are not declared correct: independent fold-back, generation, no-alias and operation/prefix checks remain required. This module grants no source or release approval.
