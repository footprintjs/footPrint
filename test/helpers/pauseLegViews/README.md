# Pause field ownership — test helper, author draft, UNRUN

One job: validate explicit field-capture owners and partition unchanged retained strings into actual-leg views. No observations are created or joined. The closed field inventory is the existing Drive output, bounded by its twenty-pause loop. Missing, extra, duplicate, wrong-leg, non-string, accessor-backed or later-changed output fields refuse before any read-law admission.

Each actual leg owns its log/state/init/sub/folds and optional red/redsub strings. A checkpoint and its separately retained tree belong to the leg that ended at that checkpoint. Final runError/errors/pauses belong to the final actual leg. Only sub/redsub field names change to the existing closed read-retention names; the physical-name map reverses that rename with all strings unchanged. This is proof-input consistency, not authenticity or a state model.

The adjacent tests use inert strings only and remain UNRUN. They do not prove that any native read, retained stage, checkpoint or field byte is lawful; the existing actual-leg native relations do that separately.
