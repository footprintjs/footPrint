## One guard, closed strategies

- `program.ts` reads the actual immutable program pointer and encoding.
- `common.ts` requires exact program/leg, every BUILD fold-back, the FIRST raw differing commit, coherent baseline there, checked tombstone/native read pair, real operation/call membership and order, and actual inner encoder/receiver/frame/buffer/epoch joins. These checks execute before strategy dispatch.
- The closed WRITEBACK or CHART strategy returns only actual declared StageContext write rows. It never returns a cause.
- `nativeWrites.ts` independently accounts for EVERY actual write call and every stage-origin native buffer write inside the operation. Direct calls must have exactly one corresponding physical producer, the exact argument value/object ID, frame, buffer and epoch. An extra write cannot hitchhike beside a valid read.
- Outside the proved operation, the one native comparator requires exact prefix semantics (method, arguments, result, outcome, order, canonical address, value and existing encoder bytes); actor header/frame identity is judged by the caller's existing firstDifference/R13 record view. Within the operation, every existing branch membership/order/object/frame/buffer/epoch/producer join stays mandatory. Only after all common and strategy checks succeed does the facade return the named cause/coordinate and nativeTrace metadata. The established downstream clause remains the existing owner's responsibility; generation, no-alias and actual checkpoint-start controls remain unconditional.

For `copy`, the destination differs from the read key. The common guard verifies the actual canonical read ends with its actual user path/key operand, takes the remaining OBSERVED prefix, then requires the actual write producer address to equal that prefix plus the actual write operands. It never recognises a `runs` spelling or guesses a namespace/global fallback. `checkedPair` independently requires either canonical own-base provenance or the strictly observed unchanged owning-heap fallback; this write-address calculation never supplies that read proof or guesses a namespace.
