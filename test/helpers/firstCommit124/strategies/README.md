# Closed fixture branch strategies — static successor, unrun

One job: validate unchanged fixture branch arguments and identities, and return only the actual StageContext write rows those branches declare. No strategy returns a cause. Common FIRST/read-pair/receipt/producer/prefix guards surround every strategy.

The original delReadBack strategy is moved as a whole branch check from the earlier carrier. It still proves the existing edit helper, SAME returned object, exact old/new calls and the new undefined no-op edit. It declares both the internal delete and old write, so common validation accounts for every real native write.

chartBranch.ts checks exact arguments and local identities; the small chart.ts adapter converts only its declared-chart-branches result into a common plan. same/copy retain exact top-level identity; primitive spread/batch/revert shapes keep their exact argument projection. mergeFirst preserves primitive behavior and can embed an existing read object only through the already captured result/argument IdentityGraphs: read root to argument y, or read index 0 subtree to argument index 0. Graph roots must match the actual top-level object IDs and every embedded descendant must retain its SAME within-run ID; missing, duplicate, changed or extra subtree facts refuse. Values and call tails still match the closed original branch. This adds no new observation or model. Literal-only fallback shapes with identical old/new writes still cannot explain a changed commit. Other nested materialised embeddings, proxy-heavy branches, ref/cycle facts and unobserved identities remain refused. No source operation, materialise function, generator or corpus changes here.
