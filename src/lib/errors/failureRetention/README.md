# Native failure retention

The native failure class registers a private reader for its current pending token.
Only that token owns a clear, masked or unknown receipt. Existing adoption transfers
the token; completing a child cannot erase the parent's selected token. A new capture
or completed leg releases it. Equal thrown strings and reused Errors grant no history.

Commit-failure observation writes an unknown marker independently of optional closure
tracking. A separate sticky weak bit preserves it across repeated unknown projections.
The engine producer publishes the actual projection; the parent consumes it
before applying its own diagnostic selector. No payload, member or schema is added to
public state. Tests beside this file exercise the real native owner, not mock tokens.
Contained error results capture that decision on their actual final envelope before
native completion. Per-rule weak annotations contain no pending owner, frame or live
callback. Clear result slots and supported masked scalar/object slots stay distinct;
the existing cycle/alias copier applies their decision without changing raw results.

Contained thrown functions use a weak object-like safe structured projection. A
masked Symbol uses its already-retained text only at the actual envelope result
slot; no Symbol-value history is stored. Clear/no-policy slots keep the original
function or Symbol, and null/undefined/booleans are never swapped.
