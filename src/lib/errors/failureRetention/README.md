# Native failure retention

The native failure class registers a private reader for its current pending token.
Only that token owns a clear, masked or unknown receipt. Existing adoption transfers
the token; completing a child cannot erase the parent's selected token. A new capture
or completed leg releases it. Equal thrown strings and reused Errors grant no history.

Commit-failure observation writes an unknown marker independently of optional closure
tracking. The engine producer publishes the actual projection; the parent consumes it
before applying its own diagnostic selector. No payload, member or schema is added to
public state. Tests beside this file exercise the real native owner, not mock tokens.
