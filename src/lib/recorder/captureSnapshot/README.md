# Automatic capture snapshot dispatch

This private registry selects a capture strategy by a built-in snapshot method's function identity. It stores no recorder instance or capture context. Unknown methods, including overrides, remain ordinary author hooks with their original receiver. No public recorder interface or global capture mode is added.

The runner creates one synchronous context for the whole automatic collection. Known composite strategies share the inert copier's 100,000-node and root-at-zero depth-256 bounds, count each visited hook before calling it, and refuse active cycles. Repeated shared children consume the same budget; they are not memoized. The context is discarded after collection. Returned fields still use the single bundle copier, and nested data gets one aggregate preparation copy before privacy.

These bounds cover library-owned expansion, not arbitrary author hook work or JavaScript Proxy reflection. Refusal leaves capture unknown. Explicit public snapshots keep their previous behavior. Adjacent tests cover dispatch, cycles and finite work.
