# Native stage escape preparation

Synchronous commit and retention shared by linear, decider and selector stage catches.
A failed commit keeps its own native failure. A completed pause serves its payload
once for the note and existing event. The caller retains logger and narrative lookup
order, the original exception, and rethrow; these helpers add no Promise turn.

Adjacent tests cover commit/serving order and single ownership. Complete operational,
privacy and hostile-error cases live beside `memory/storedEvidence` and the handlers.
