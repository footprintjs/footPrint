# Native subflow boundary observations

The facade `../handoff.ts` composes input seed, generated dispatch and parent collection observations. Input capture and fanout capture are independently off by default; existing output capture is unchanged. `native.test.mjs` runs real charts beside these modules.

Input metadata names literal parent root reads at an exclusive pre-mapper cutoff and actual child seed trace paths. Resumed seeds, privacy, unavailable selector observations and a moving parent log retain explicit partial limitations. No parent key is inserted in child readKeys. Generated origins live only in a code-owned WeakMap, shared by the native mount options object.

Fanout collection metadata names the actual parent array commit and real child log cutoffs in item order. A missing child omits its entire slot. Scope snapshots are not key reads or element derivations: readers must keep them nontraversable with a boundary gap. Explicit returns and failed slots remain partial. Parent collections are bounded to128 within4096 items/64KiB; fresh runtimes own fresh collectors, and snapshots copy their view without reconstructing the tree. Native invocation inventories always remain partial, even when a particular observation is captured.

Privacy withholds input source names and collection child references, including explicit redacted root and nested serving. These value-free memory observations confer no storage, whole-run completeness or semantic causality receipt.
