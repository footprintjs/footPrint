---
title: foottrace/write — write a record
description: Writing a record without running a flowchart is done with the foottrace package, which has its own documentation.
---

`foottrace/write` belongs to the **foottrace** package, not to footprintjs. foottrace owns the run record: its
writer, its readers and the rules for both. footprintjs writes every run through it, but does not re-export it.

```ts
import { EventLog, RecordFrame, SharedMemory } from 'foottrace/write';
```

The writer and its contract are documented with the package:

- [foottrace on GitHub](https://github.com/footprintjs/foottrace#readme)
- [The record contract and writing guide](https://github.com/footprintjs/foottrace/blob/main/docs/guides/record-contract.md)

For an engine-side example, see
[`examples/post-execution/time-travel/07-write-a-record.ts`](https://github.com/footprintjs/footPrint/blob/main/examples/post-execution/time-travel/07-write-a-record.ts).
