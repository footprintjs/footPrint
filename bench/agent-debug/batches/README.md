# Batches: every paid run, kept

RULE.md, rule 2: every paid run is kept, with its full transcript, its tool calls and its usage numbers; nothing is deleted or run again to get a better number. A batch is made in a new empty folder outside the repository and copied here unchanged when it is done.

| Folder | What it is | Result |
|---|---|---|
| `2026-11-12-smoke-1/` | The smoke batch: one fault, once in each set-up, to check the connection and the accounting. Not part of any result. | All five start conditions of RULE.md 1.5 met (`report.md` ends with the checklist). |
| `2026-11-12-batch-1/` | The pilot: ten faults, three set-ups, three runs each, 90 runs. | "Stop and look": the saving is not shown. Read [RESULT.md](2026-11-12-batch-1/RESULT.md). |

Each folder holds what the harness wrote: `order.json` (the plan, its seed, the commit and the library versions), `started.jsonl`, `runs.jsonl` (one row per run), `report.md` (generated by `harness/report.mjs`), and `transcripts/` (everything the model was sent and everything it answered). A batch's `review/` folder holds the scripts an independent reader used to check it, with their outputs.

A new batch is a new experiment: its rule is written and committed first, and it gets its own folder.
